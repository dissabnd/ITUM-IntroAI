# Hands-On Lab 2: Process Dynamics with Copilot Chat



## Industrial Problem & Learning Objectives
An open tank receives a liquid feed and drains through an outlet valve. When the inlet flow is suddenly increased from 20 to 30 m³/h, how does the liquid level change over time, and where does it settle? You will use **Copilot Chat** to build the model, derive the transfer function and plot the level response **h(t)**, then check whether the AI's answer is correct and whether it holds its ground when challenged.
